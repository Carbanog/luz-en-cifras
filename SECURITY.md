# Seguridad

## Versiones compatibles

Solo la última release publicada recibe correcciones. Las versiones anteriores
se conservan para recuperación; no se mantienen en paralelo.

## Informar de una vulnerabilidad

No publiques credenciales, CUPS, direcciones, facturas ni registros completos en
una incidencia pública. Usa el aviso privado de seguridad del repositorio de GitHub
cuando esté disponible. Si todavía no lo está, abre una incidencia sin datos
sensibles solicitando un canal privado de contacto.

La integración no necesita credenciales. El modo PVPC directo consulta precios
públicos de Red Eléctrica; las otras modalidades utilizan entidades y datos locales.
Un informe útil debe indicar la versión afectada, el impacto, una reproducción mínima anonimizada y
si requiere acceso local o remoto.
